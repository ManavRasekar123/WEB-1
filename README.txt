Athletes Arena - turf booking website (demo)
Open index.html in any browser. Single file: HTML + CSS + JS, no install needed.

Demo notes:
- Prices, turf details and the payment step are placeholders (no money is charged).
- Bookings are stored only in the visitor's browser (localStorage).
- Owner panel: open the footer link "Owner login", demo PIN 1234.
- To go live: add a backend + database, Razorpay for the advance payment,
  and real photos/logo/contact details from the owner.
